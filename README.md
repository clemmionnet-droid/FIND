# FIND — vraie base mobile V1

Projet Expo/React Native destiné à devenir la vraie application FIND.

Cette première base contient :
- navigation mobile native
- feed
- découvertes
- profil et collections
- ajout/scanner (interface)
- cadeaux
- likes et commentaires (UI)
- architecture prête pour brancher le backend

Prochaine étape technique : connecter Supabase pour rendre les comptes, collections, follows, posts, likes, commentaires, messagerie et notifications persistants et multi-utilisateurs.

Tu n'as pas besoin de modifier le code pour la suite.
